# Digital Evidence Relevance Classification Dataset

This 3000-row dataset is synthetic and was generated by
`ml-service/src/generate_dataset.py`. It is intended for development and
experimentation with a Digital Evidence Relevance Classification model.
An earlier 600-row version was used for the first training run.

## Label generation

Each row receives a hidden weighted relevance score. The score combines:

- suspicious IP status
- shared IP and device counts
- file attachment presence
- tag count
- evidence proximity to the incident time
- relevant versus routine description text
- evidence type
- case type
- random noise

The hidden score is divided into Low, Medium, and High classes using
calculated thresholds selected to produce approximately 35% Low, 40% Medium,
and 25% High. No hidden score or noise value is saved in the CSV.

To represent human disagreement, roughly 8% of labels near either threshold
are randomly changed to a neighbouring class.

## Columns

- `evidence_type`
- `case_type`
- `source`
- `description`
- `tags`
- `hour_of_day`
- `hours_from_incident`
- `ip_is_suspicious`
- `shared_ip_count`
- `shared_device_count`
- `has_file_attachment`
- `tag_count`
- `relevance_label`

## Limitation

The labels and feature relationships are artificial. Strong or weak model
performance on this dataset does not prove that the model would perform
accurately on real forensic evidence, and the dataset does not replace
forensic validation or expert review.
